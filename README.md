# kyon.sh

The Kyon website: one static page, served by GitHub Pages from this repository's
default branch.

Kyon itself — downloads, issues, source — lives in
[kyon-sh/kyon](https://github.com/kyon-sh/kyon).

`CNAME` is what points `kyon.sh` here; removing it drops the site back to
`kyon-sh.github.io`.
