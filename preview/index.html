    What it does

    Built around the way you already work

    ~/orbit git:(main)

    A terminal built around commands

    Every command and its output is a block you can select, copy, rerun or hand to the agent. The input is a real editor, with completions, history, corrections and Vim keys if you want them. Secrets that appear on screen are hidden, and prompt themes' icons and box drawing come out crisp with no fonts to install.

    ⌘↵ find the five largest files here

    Say what you want, ask on the side

    Write what you want in the terminal and ⌘↵ turns it into the command, ready to read and run. Ask questions in a pane beside a coding agent without interrupting it. Kyon's own agent reads and edits files and runs commands, asking first as much as you want it to, and follows your rules files and MCP servers.

    ask with: codex · private: ~/clients

    Your model, and private stays private

    Answer with the coding agent you already use, with nothing to set up, or any OpenAI- or Anthropic-compatible endpoint. Mark a folder private and only a model on your own machine reads it; your coding agent can ask that private model and gets an answer, not the data, once you let it go.

    claude · codex · gemini · opencode

    Your other coding agents, better

    Start Claude Code, Codex, Gemini, OpenCode or Pi, here or on a server. One list shows every agent in every window, the ones waiting for you first, and the Dock counts them. Send a selection, a file or a command's output to the agent working on it, review exactly what its last turn changed and send your comments back, and give every agent Kyon's own tools over MCP. After a restart they come back with their conversation.

    src/limiter.rs:22

    Code, review and documents

    An editor with language servers, a file explorer, workspace search, review over git with comments on any line, and Markdown you edit as it is rendered, Mermaid diagrams included. All of it works offline.

    layout restored · 3 tabs

    Yours to arrange

    Tabs, splits, vertical tabs, saved layouts, launch configurations and themes. Tabs colour themselves by rules about the user, the machine, the folder or the command, so root and production stand out. Settings live on a page or in a plain file. Quitting asks first, and after a restart, or a crash, the workspace comes back as you left it.

    Remote machines

    Work on a server as if it were this machine

    Connect over SSH and the terminal, editor, file explorer, search and review all work on that machine. Sessions there, coding agents included, keep running when you disconnect and are waiting when you come back. A dropped connection is made again by itself, and what you typed meanwhile goes through once it is back. Drop a file of any size on a terminal there and it is copied across.

    ✓ Nothing listens on a port ✓ No password of ours: SSH is the only way in ✓ Any Linux or macOS host, x86_64 or ARM64 ✓ Reconnects by itself, without losing a keystroke ✓ Fast over remote desktop, with or without a GPU
