Every setting

Every setting in Kyon, page by page as the Settings window shows them, with what it does and its default.

How settings work

Open Settings with ⌘,, or from the menu behind the button at the right of the title bar. The window lists the same pages as this reference, and its search field finds a setting by any word of its name or description.

Every setting is also kept in a plain settings file you can edit by hand: run Open settings file (⌥⌘,) from the command palette. Kyon notices within a second when the file changes and applies it. If something in the file is wrong, the window says what, keeps the rest of your settings, and offers to open the file.

Some settings only appear while another is on, the way the window shows them. A setting marked after a restart takes effect the next time Kyon starts.
