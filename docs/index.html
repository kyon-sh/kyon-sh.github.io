How to use Kyon, the AIDE: the terminal, the editor and your coding agents in one window.

What Kyon is

Kyon is an AIDE, an AI development environment. Your terminal, an editor beside it and the coding agents you already use, from Claude Code and Codex to Gemini, OpenCode and pi, work together in one window. Run several agents at once, see at a glance which one is waiting for you, review exactly what each changed, and keep them working on a server while your laptop is closed.

New to Kyon? Start with Getting started. Looking for one thing? The command list and settings reference cover everything, and inside Kyon the command palette (⌘P) finds any command by name.
