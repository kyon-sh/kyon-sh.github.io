Commands and shortcuts

Every command in Kyon, by area, with its keyboard shortcut on macOS and on Linux and Windows.

Finding a command

Everything Kyon can do is a command, and every command is in the command palette: press ⌘P and type a few letters of what you want. A command's shortcut is shown beside it.

To change a shortcut, run Keyboard shortcuts from the palette (it is also in Settings), find the command, press its row and then the keys you want. The same bindings are kept in a keybindings file, which Open keybindings file opens.
